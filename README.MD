### Описание приложения

**Приложение "Список фильмов"** - это Android-приложение для просмотра коллекции фильмов и сериалов с возможностью детализации.

Ключевые особенности:
1. **Главный экран (MainActivity)**:
    - Отображает адаптивную сетку карточек фильмов (2 колонки в портрете, 3 в ландшафте)
    - Поддержка планшетов с динамическим расчетом размеров элементов
    - Темная тема оформления (#1B1E26)

2. **Навигация и архитектура**:
    - Второе активити для детализации заменено на **фрагмент (DetailFragment)**
    - Используется единый контейнер для фрагмента детализации
    - Back stack для управления историей навигации

3. **Анимации**:
    - **Shared Element Transition** для плавной анимации изображения при открытии
    - В портретном режиме детализация выезжает снизу с затемнением фона
    - При закрытии в портрете - анимация сдвига вниз
    - Кастомные переходы с ChangeBounds/ChangeTransform (500ms)

4. **Адаптивный дизайн**:
    - **Для планшетов**:
        - Детализация открывается **на том же экране справа** 
         - Одновременный показ списка и деталей
    - В портрете телефона - полноэкранная детализация
    - Динамический расчет высоты карточек под разные устройства

5. **Экран детализации**:
    - Полная информация о фильме: заголовок, рейтинг, жанр, описание
    - Горизонтальная прокрутка актерского состава
    - Градиентный оверлей на постерe для улучшения читаемости текста
    - Возрастной рейтинг и кнопка назад в верхнем углу

6. **Технические особенности**:
    - Обработка поворота экрана с сохранением состояния
    - Оптимизация памяти при загрузке изображений актеров
    - Кастомные тени и закругленные углы элементов
    - Поддержка RTL и доступности (contentDescription)

Приложение демонстрирует современные подходы Android-разработки:
фрагментную навигацию, адаптивный UI, плавные анимации и оптимизацию под разные размеры экранов.
Особый акцент сделан на seamless-переход между списком и детализацией через shared element transition.
